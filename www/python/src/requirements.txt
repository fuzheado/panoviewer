# (Help:Toolforge/Web/Python: "On the Kubernetes backend, you must use a virtual
# environment to install and load any libraries you depend on outside of the
# Python standard library"). Create it INSIDE a webservice pod -- a venv made on
# the bastion is the wrong interpreter and will not load.
#

# job image can be the stock python3.11 image (which has neither).
